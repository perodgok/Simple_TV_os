# Simple TV OS 1.0 — аудит и статус редизайна

## Состояние
Ветка `feat/premium-redesign-1.0` предназначена для review. В `main` остаётся предыдущая версия. Создан локальный исходный архив `SimpleTVOS-1.0-rc1-source.zip`; **перед merge полный код должен быть загружен в эту ветку, собран и проверен на устройстве**. На данном этапе ни сборка с Android SDK, ни тест на Xiaomi не подтверждены.

## Что выявлено в имеющемся v0.6
- Визуальная система построена на стандартных `Button` и системных `AlertDialog`; нет единообразной композиции, карточки залиты разными цветами.
- Метод `renderFavorites()` полностью удаляет и заново добавляет Views, что усложняет фокус и события долгого OK.
- Метод `cancelMove()` v0.6 НЕ восстанавливает порядок, изменённый стрелками во время перемещения (хотя не сохраняет его в Preferences, текущая сессия остаётся изменённой).
- `endDrag()` и обработка `KeyEvent.ACTION_UP` зависят от `suppressNextOkUp` и при особых последовательностях событий могут конфликтовать. Требуются тесты на реальном пульте.
- `showAllApps()` загружает все иконки и создаёт все ячейки одновременно, без ленивой переработки большого списка.
- `showInputs()` вызывает только vendor-панель при нажатии любого пункта; прямой выбор источника не реализован.
- HAPP с пакетом `su.happ.proxyutility` установлен, но по реальному логу `monkey` не нашёл standard activity, поэтому гарантировать запуск нельзя.

|---|---|---|---|

| [LTvLauncher](https://github.com/leanbitlab-org/LtvLauncher) | `lib/flauncher.dart`, `lib/custom_traversal_policy.dart`, `lib/models/`, `lib/providers/`; шапка исходника GPL | Разделение состояния, видов, логики | Flutter/GPL; берём архитектурный принцип |
| [flaunchermod](https://github.com/ctnkyaumt/flaunchermod) | `lib/actions.dart`, `lib/database.dart`, `lib/custom_traversal_policy.dart` | События пульта, состояние избранного | Основан на Flutter/FLauncher; лицензии требуют отдельной проверки |
| [OpenMonitor](https://github.com/1orz/OpenMonitor) | В корне исследованы `README` и `LICENSE`, **Android-кода в корне не обнаружено** | Общие идеи мониторинга без копирования кода | Нельзя выдавать за библиотеку для Android TV |
| [android-tv-dashboard](https://github.com/msbroy/android-tv-dashboard) | `tvdash/collectors.py`: `StateTracker` считает дельты CPU jiffies/счётчиков сети | Сравнение последовательных измерений, не вывод мгновенных значений из накопительных | Внешний Python ADB dashboard, не приложение Android TV |

Новая реализация планируется на Java и стандартном Android API, без стороннего или скопированного кода. Из GPL-проектов не переносились исходники, изображения и ресурсы.

## Изменения в исходном кандидате RC1
- Нейтральная тёмная палитра, мягкие полупрозрачные карточки, оригинальные иконки, анимация фокуса 175 мс.
- Обои: системный документ-пикер, сохраняемый доступ URI, downsampling RGB_565, затемнение, четыре встроенных градиента.
- Отдельный экран «Система» с API RAM/Storage, CPU из `/proc/stat`, доступной температурой и метаданными. Неподдерживаемые показатели показывают «Недоступно».
- Перестановка: долгое OK включает перемещение, стрелки изменяют порядок, повторное OK сохраняет, BACK восстанавливает исходный список.
- HDMI: доступные входы и состояния из TV Input Framework, локальное переименование, fallback на vendor-панель.
- Плитки приложений запускают Leanback / Launcher Intent; HAPP не может запускаться без экспортированной Activity.

## Проверки и ограничения
- Bash синтаксис сборщика: PASS.
- Java SDK compilation: НЕ ПРОВЕРЕНА, SDK доступен на Mac пользователя, но не в среде создания архива.
- Установка APK/работа HOME/расход RAM и fps: НЕ ПРОВЕРЕНЫ.
- Подпись: обязательно использовать существующий `~/simple-tv-os/keys/simple-tv-os.jks`; никогда не публиковать её.
- Сценарий восстановления: `adb shell pm enable --user 0 com.google.android.tvlauncher`; после этого `cmd package set-home-activity com.google.android.tvlauncher/.MainActivity`.

## Перед слиянием
1. Передать полный архив источников в ветку.
2. Запустить `javac`/Android-сборку и устранить ошибки.
3. Установить на Xiaomi, проверить порядок, BACK, список, URI-обои, HDMI, HAPP, возвращение из Settings и HOME.
4. Собрать ADB metrics и `dumpsys meminfo com.simpletvos.home` для сравнения с предыдущей версией.
5. Только после тестирования merge в `main`.
