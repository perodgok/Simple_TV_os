# Simple TV OS — история проекта и состояние последней сборки
**Дата:** 23 октября 2026 г.  
**Устройство:** Xiaomi MiTV-MOOQ1 / `tarzan` / Android TV 11 / MediaTek m7632 / 43″ BOE LED  
**Проверенный идентификатор прошивки:** `RTM4.220307.164.8277 release-keys`  
**Пакет приложения:** `com.simpletvos.home`  
**Последний подготовленный исходный ZIP:** `SimpleTVOS-KION-panel-backlight-0-50.zip` (локальная сборка для установки с Mac; **не системная прошивка Android**).

> **Правило достоверности:** отличаем наличие функции в исходниках, подтверждение записи Android-параметра, визуальное подтверждение на экране ТВ и успешную установку APK. Заявление «APK уже установлен» требует вывода установщика, которого для финального ZIP в переписке пока не предоставлено.

## 1. Хронология работы

### Подготовка
1. Организовали проект Simple TV OS — сторонний Android TV launcher без root, под MacBook M1/macOS Monterey. Настройка ADB по TCP/IP `192.168.0.108:5555` (IP может измениться), JDK 17, Android SDK API/build tools 35 и подписание тем же локальным keystore.
2. Реализовали последовательные прототипы v0.1–v0.6, затем ветку визуального интерфейса **1.0 Classic**. Подготовили ZIP с исходниками, сборкой через `aapt2`/`javac`/`d8`/`apksigner` и установкой через ADB; APK собирается на Mac, а не в чате.
3. Исправляли интерфейс: в частности, левый край круглой иконки избранного обрезался, поэтому добавили внутренний отступ и отключение клиппинга контейнера (проверять окончательный вид на ТВ после установки).
4. Изучили запуск Xiaomi PatchWall/Google Launcher и замену HOME. Никаких системных прошивок не прошивали и root не выполняли.

### Кнопки пульта / HOME
5. Проверили физические коды Xiaomi RC Consumer Control (`/dev/input/event2`):
   - Wink `197`
   - KION `198`
   - IVI `199`
   - Okko `200`
   - Kinopoisk `201`
   - Rutube `203`
6. Обнаружили системные цепочки `MiTVWindowPolicyInjector` → `ACTION_GLOBAL_BUTTON`; ресиверы `com.mediatek.tv.service/com.mediatek.hotkey.dispatcher.GlobalKeyReceiver` и `com.xiaomi.android.tvsetup.partnercustomizer/.GlobalKeyReceiver`.
7. Встроили **AccessibilityService** `com.simpletvos.diagnostics.RemoteKeyAuditService`. Сначала было `accessibility_enabled=0`, затем служба активирована; реальное нажатие Wink записано в `SimpleTVRemote: key=197 action=0 repeat=0`.
8. Исследовали конфликт двух HOME: когда включён `com.google.android.tvlauncher`, он получает приоритет HOME 2, Simple TV OS — 0, даже после успешного `set-home-activity`. Откат с отключением Google возвращал HOME к Simple TV OS.
9. Приняли и проверили пользователем более простую схему: **HOME → Google Launcher, Wink → Simple TV OS**. В текущем Java-коде Wink запускает `com.simpletvos.home/.MainActivity` напрямую.
10. Коды IVI/Okko/Kinopoisk в Accessibility намеренно **пропускаются** (метод возвращает `false`); это не гарантия запуска их штатных приложений, если приложения удалены отдельно.

### Подсветка
11. Первые попытки меняли `Settings.System.screen_brightness` (0↔128/255). На данной модели это не подтвердило изменение **штатной LED-подсветки панели**; решение признали неподходящим.
12. Полный read-only аудит устройства выявил `TvService`, MediaTek TV components, Android DisplayManager; сравнение снимков при штатной подсветке 50 и 10 не выявило изменений стандартного `screen_brightness`.
13. Перешли к предполагаемому OEM параметру **`Settings.Global.picture_backlight`**. В диагностике на ТВ успешно прошёл цикл:
   - исходное `picture_backlight=50`
   - после установки 50 → readback `50`
   - после установки 0 → readback `0`
   - после установки 50 → readback `50`
   - автоматический откат → readback `50`.
   Пользователь написал «работает»; предоставленный терминальный лог **строго доказывает изменение значения в Settings**, а изменение физической яркости подтверждается только визуальным наблюдением пользователя. Не следует автоматически считать, что это аппаратный API, пока изменение экрана не проверено.
14. Подготовили `SimpleTVOS-KION-panel-backlight-0-50.zip`: `BrightnessControl.java` читает/пишет `Settings.Global.picture_backlight`; код кнопки KION вызывает его **без отдельного окна**. В манифесте `WRITE_SECURE_SETTINGS`, в установщике `pm grant com.simpletvos.home android.permission.WRITE_SECURE_SETTINGS` (требуется успех grant). Если права нет, ошибка записывается в `SimpleTVRemote`.
15. В данном разговоре **нет журнала успешной установки/нажатия KION именно этой финальной сборки**, поэтому статус — *код готов, реальное действие KION на ТВ после установки не подтверждено*.

### Таймер, удаление приложений
16. Добавили на главный экран Simple TV OS кнопки подсветки и таймера, плюс отдельный экран таймера 60/90 минут и отмену через `AlarmManager`. **Критическое ограничение:** текущий `SleepAlarmReceiver` вызывает `AccessibilityService.GLOBAL_ACTION_LOCK_SCREEN`; это **не доказанный standby/отключение HDMI**, физический сон ТВ не реализован.
17. В предыдущих ZIP подготовили инструменты поиска и удаления для пользователя 0: KION, Яндекс Браузер, Mi Обои, Okko и OpenVPN for Android (пакет-кандидат `de.blinkt.openvpn`). Сам факт подготовки скриптов **не доказывает, что соответствующие приложения уже удалены**. В последней ZIP присутствует отдельный `УДАЛИТЬ_OKKO.command`, но установщик KION не вызывает его автоматически.
18. PatchWall был отключён в ходе работы, а не удалён. В последнем пакете нет действий для отключения PatchWall, изменения системного keylayout или удаления системных MediaTek-сервисов.

## 4. Ограничения / что осталось

- Проверить физическую реакцию LED-подсветки при изменении `picture_backlight` и нажатии KION после финальной установки; чтение значения `settings get global` само по себе недостаточно.
- Проверить, что AccessibilityService по-прежнему включён и `pm grant` выдал `WRITE_SECURE_SETTINGS`, иначе KION будет молчать.
- Старый экран `RemoteControlsActivity.showBacklight` содержит устаревшие пояснения-заглушки об OEM подсветке — интерфейс нужно привести в соответствие с новым `BrightnessControl`. Это **не влияет на прямое нажатие KION**, но является техническим долгом.
- Заменить `GLOBAL_ACTION_LOCK_SCREEN` на подтверждённый системный standby Xiaomi/MediaTek; иначе 60/90 минут не гарантируют выключение телевизора при HDMI/видео.
- Не удалять сервисы MediaTek, не писать в системные `.kl` и не менять прошивку без проверенного безопасного восстановления.
- Обновления Android/Google Launcher могут менять HOME приоритет; рабочая схема HOME Google / Wink Simple TV OS предпочтительнее борьбы с HOME приоритетами.

## 6. Инструкция проверки последней сборки

На Mac:
```bash
cd ~/Downloads
unzip -oq SimpleTVOS-KION-panel-backlight-0-50.zip
bash SimpleTVOS-1.0-classic-buttons/УСТАНОВИТЬ_НА_ТВ.command
```

После установки, при включённой Accessibility:
```bash
TV=192.168.0.108:5555
adb -s "$TV" shell settings get global picture_backlight
adb -s "$TV" shell settings get secure enabled_accessibility_services
adb -s "$TV" shell dumpsys package com.simpletvos.home | grep WRITE_SECURE_SETTINGS
adb -s "$TV" logcat -d -s SimpleTVRemote:I '*:S' | tail -n 30
```

**Безопасное восстановление подсветки:**
```bash
adb -s 192.168.0.108:5555 shell settings put global picture_backlight 50
```

**Статус:** Последняя подготовленная сборка — **Simple TV OS 1.0 Classic / KION picture_backlight 0↔50**; пользователь подтвердил успешное чтение/запись `picture_backlight`, но лог установки финального APK пока не приложен.
