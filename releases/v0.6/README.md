# Simple TV OS v0.6 — кандидат на выпуск

Статус: **исходный архив подготовлен локально, но сборка и работа на Xiaomi TV ещё не подтверждены**. Не считать проверенным релизом.

## Изменения

- Удержание OK на плитке включает режим перестановки. После отпускания кнопки плитка перемещается стрелками; повторный OK фиксирует позицию.
- В правом верхнем углу круглая кнопка системных настроек с короткой анимацией.
- На плитках используются оригинальные иконки установленных приложений с резервным отображением.
- Сохраняются HAPP, список приложений и меню источников из предыдущих версий.

## Устройство

Xiaomi MiTV-MOOQ1 (`tarzan`), Android TV 11, `armeabi-v7a`; ADB через Wi-Fi. Пакет HOME: `com.simpletvos.home`. Штатный Google Launcher отключён только для user 0, но не удалён.

## Восстановление штатного HOME

```bash
adb connect 192.168.0.108:5555
adb -s 192.168.0.108:5555 shell pm enable --user 0 com.google.android.tvlauncher
adb -s 192.168.0.108:5555 shell cmd package set-home-activity com.google.android.tvlauncher/.MainActivity
adb -s 192.168.0.108:5555 shell input keyevent 3
```

Полная инструкция: [`docs/STATUS_AND_RECOVERY.md`](../../docs/STATUS_AND_RECOVERY.md).
